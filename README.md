# Indian Rash Driving 🚗💨🇮🇳

**Indian Rash Driving** is a web-based 2D/2.5D driving game focused on fast-paced traffic dodging and chaotic road encounters.

The player drives along a four-lane road, avoiding incoming vehicles and trying to survive for as long as possible. The game is designed to be simple to pick up, fun to play, and progressively more challenging.

The **"Indian"** in *Indian Rash Driving* has a specific purpose within the game's concept. Its meaning and significance will be revealed and documented as the project develops.

## Purpose

The purpose of this project is to create a lightweight, entertaining browser game centered around driving, quick reactions, traffic, and increasingly chaotic situations.

This README will be updated as the game's concept and the reason behind its name become clearer during development.
