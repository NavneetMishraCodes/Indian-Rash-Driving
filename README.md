# Indian Rash Driving 🚗💨🇮🇳

**Indian Rash Driving** is a web-based 2D/2.5D driving game focused on fast-paced traffic dodging, quick reactions, and increasingly chaotic road encounters.

The player drives along a four-lane road, avoiding incoming vehicles and trying to survive for as long as possible. The game is designed to be lightweight, accessible, entertaining, and progressively more challenging.

The **"Indian"** in *Indian Rash Driving* has a specific purpose within the game's concept. Its meaning and significance will be revealed and documented as the project develops.

---

## 🎮 Purpose

The purpose of this project is to create a lightweight browser game centered around:

* Fast-paced driving
* Traffic dodging
* Quick reactions
* Increasing difficulty
* Chaotic road encounters
* Arcade-style gameplay
* Desktop and mobile accessibility

The project is actively developed and its gameplay, visual identity, mechanics, and overall concept may continue to evolve.

This README will be updated as the game's concept and the reason behind its name become clearer during development.
